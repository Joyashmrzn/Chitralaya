Chitralaya 🎨

A full-stack art e-commerce marketplace connecting artists with buyers — built with React and Django REST Framework.

Live Demo:(https://chitralaya-project.vercel.app/)
Features
🛒 Full e-commerce flow with 2-step checkout
💳 Multiple payment options: eSewa, Khalti, and Cash on Delivery (COD)
📦 Admin order management dashboard
📍 Shipping address module
🧾 PDF receipt generation and download
📊 GA4 analytics and Google Search Console integration
📱 Mobile-responsive design with hamburger navigation and slide-out filter drawer
🖼️ Fullscreen image lightbox for artwork previews
☁️ Cloudinary-powered media storage and optimization


Tech Stack

Frontend:
    React + Vite
    Deployed on Vercel

Backend:
    Django REST Framework
    PostgreSQL
    Gunicorn
    Deployed on Render


Other Integrations:
    Cloudinary (media/image storage)
    eSewa & Khalti (payment gateways)
    Google Analytics 4 (GA4)
